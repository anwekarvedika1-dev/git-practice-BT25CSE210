## Description
This repository contains the exercises I completed for the IT Workshop I Git and GitHub assignment. It shows creating a repository, branching, merging, resolving a merge conflict, and using issues and pull requests.

## Completed Exercises
- [x] exercise-01: Greeting script
- [x] exercise-02: Menu script (greet, add two numbers, even or odd, exit)
- [x] exercise-03: Merge conflict practice

## How to Run
These are Bash scripts, so no compiling is needed. Open Git Bash in this repository and run:

    cd exercise-01
    bash greet.sh < input.txt

    cd ../exercise-02
    bash menu.sh < input.txt

Each exercise folder has its sample input in input.txt and its sample output in output.txt.
